# EloriaGim — Modern Fitness Club Landing Page

Štýlová, moderná a plne responzívna landing page pre fitness klub.
Navrhnutá tak, aby prehľadne prezentovala služby, trénerov, cenník a kontaktné možnosti v čistom a dynamickom dizajne.


## Features

- Plne responzívny dizajn (mobil, tablet, desktop)

- Moderné UI s plynulými animáciami

- Hero sekcia so silným vizuálnym efektom

- Prehľad služieb s ikonami

- Sekcia trénerov

- Cenník tréningových programov

- Kontaktné formuláre


## Tech Stack

- HTML5
- CSS3
- JavaScript
- Flexbox / Grid
- Netlify Hosting
- GitHub Pages (nasadenie projektu)


## Moja úloha (My Role)

- Koncept & UI dizajn — úplne samostatné vytvorenie štruktúry webu, vizuálnej kompozície, farebnej témy a štýlu bez použitia Figma.

- Layout development — kódovanie všetkých sekcií na základe vlastného dizajnu s premyslenou logikou rozmiestnenia prvkov.

- Responsive design — prispôsobenie webu pre mobily, tablety a veľké obrazovky s flexibilným správaním blokov.

- Animácie — tvorba plynulých prechodov a efektov, ktoré posilňujú atmosféru projektu a robia interakciu živšou.

- Optimalizácia obrázkov — optimalizácia fotografií a grafiky pre rýchle načítanie bez straty kvality.

- UI úpravy — drobné dizajnové korekcie pre lepšiu čitateľnosť, vizuálny balans a harmonický vzhľad.

- Príprava na nasadenie — príprava štruktúry projektu na publikovanie cez Netlify a GitHub Pages.
